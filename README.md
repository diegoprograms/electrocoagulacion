# Proyecto de Electrocoagulación — Física 2

**¿Podemos convertir los conocimientos de Física 2 en una solución tecnológica para contribuir al tratamiento de una problemática real relacionada con el agua en nuestro territorio?**

Construimos un solo proyecto entre todos. Cada grupo aporta sus conocimientos e investigaciones a la etapa en curso; todos aprenden sobre el sistema completo. Las ideas se comparan con evidencia y alimentan las decisiones colectivas.

Las nuevas etapas se definen conforme avanzamos. Para crear otra, copiamos la [plantilla de etapa](etapas/plantilla_etapa/README.md), asignamos el siguiente número y añadimos su nombre cuando se acuerde.

## Cómo participar

1. Leer la guía de la etapa.
2. Consultar y aportar fuentes en su carpeta de referencias.
3. Registrar datos y análisis en el Excel compartido y subir las exposiciones.
4. Comparar los aportes de los grupos en la síntesis colectiva.
5. Documentar acuerdos, evidencia y preguntas abiertas.

Cada etapa separa **referencias consultadas** de **aportes de estudiantes**. Sus README enlazan a las carpetas y Excel compartidos que ya utilizamos. No es necesario duplicarlos en GitHub. Los enlaces aún no suministrados se indican como pendientes.
