# Proyecto de Electrocoagulación — Física 2

## Pregunta guía
**¿Podemos convertir los conocimientos de Física 2 en una solución tecnológica para contribuir al tratamiento de una problemática real relacionada con el agua en nuestro territorio?**

## Metodología
Problema → Investigación → Contactos → Diseño → Construcción → Experimento → Datos → Análisis → Decisión → Mejora → Nuevo diseño.

## Equipos
1. Grupo 1 — Electrodos
2. Grupo 2 — Fuente de poder
3. Grupo 3 — Sensores y medición
4. Grupo 4 — Software y dashboard

Todos trabajan además en investigación, experimentación, relacionamiento/emprendimiento y documentación.

## Estructura
- `00_gestion`: calendario y responsables.
- `01_problema_territorial`: problemas y evidencias.
- `02_investigacion`: revisión documental.
- `03_contactos`: actores y seguimiento.
- `04_grupos`: desarrollo de cada subsistema.
- `05_datos`: datos originales, procesados y tabla maestra.
- `06_experimentos`: historial de ensayos.
- `07_prototipos`: versiones del dispositivo.
- `08_dashboard`: software.
- `09_resultados`: análisis consolidados.
- `10_emprendimiento`: usuario, costos, aliados y propuesta de valor.
- `docs`: documentos generales.

## Regla de oro
**Dato que no queda registrado es conocimiento que el proyecto pierde.**
Nunca se elimina un experimento anterior: cada iteración alimenta la siguiente.
